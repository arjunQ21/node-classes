# Messaging Application Backend 📱💬

A backend service for a group and direct messaging application, providing real-time messaging capabilities with user authentication, group management, and message routing.

## Features ✨
- **User Authentication** 🔑: Allows users to register, log in, and manage their profiles.
- **Messaging** 🗣️: Users can send messages to individuals or groups.
- **Group Management** 👥: Create public or private groups, add members, and send messages to groups.
- **Password Recovery** 🔄: Users can reset their passwords if forgotten.
- **Profile Management** 🖼️: Users can set their profile images.

## Tech Stack 🛠️
- **Node.js**: JavaScript runtime environment for the backend.
- **Express.js**: Web framework to build the API.
- **MongoDB**: NoSQL database for storing user data and messages.
- **JWT (JSON Web Token)**: For secure user authentication and message validation.
- **Mongoose**: ODM (Object Data Modeling) library for MongoDB and Node.js.
- **Bcrypt**: For securely hashing passwords.
